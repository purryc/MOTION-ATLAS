数据与解释边界

动画来自原始标记点；缺失时隐藏点与连线，不跨缺口补造动作。实心点为真实指甲标记点，校准不移动这些点；橙色空心点与高度线使用 max(0, 指甲 Z 减去触摸基线)，表示校准参考。自动校准触摸中位数为零，其他触摸帧仍可能略有偏差；可在当前已记录触摸帧手动设零。低于参考值时距离显示为 0 mm，原始带符号差值保留供核查；两个距离都不能解释为指腹净距。任务 UI 为日志锚点与触摸轨迹示意；采用机型标称像素到整个屏幕的估计映射，状态栏/应用偏移和控件尺寸未记录，不代表像素精确复刻或原始视频。阅读正文与键盘排布未重建。绿色框为当前操作全任务有效拇指位置的 XYZ 各轴 P10–P90，作为 Home Zone 位置参考，不证明存在统一静止手位，也不随停留阈值改变。停留分析独立展开，空间热度仅在报告。点击 tile/target 仅显示日志位置，不当作已知控件中心。UI 位置校准用同记录有效点击拟合像素到指甲参考 XY 的对应映射，并经过留出验证，仅转换日志控件和触点示意，不移动真实标记点；其结果不是指腹位置或已验证的物理屏幕配准。手机尺寸按官方记录构建；S3/S4/OPO 屏幕居中偏移为几何估计，N6 使用官方偏移。任务片段包含最多 ±500 ms 的推定上下文。原始数据不含主动 Hover 意图标签。触摸对齐通过时钟与覆盖检查，独立物理同步尚未建立，暂作描述性观察。
